How recommendations work

RAM guidance includes a planning allowance for runtime and context memory. It is an estimate, not measured peak usage. Available memory changes as other apps run.

A model is recommended only when both hardware fit and task quality have evidence. Task quality is currently unverified, so usable models remain conditional. A greyed-out download has a concrete resource or compatibility reason.

Completed runs with at least 16 generated tokens update this session's speed observation. They do not validate task quality. The interactive target is 8 tokens/s, a product guideline rather than a quality score. Slower models remain selectable.

Models are fetched from Hugging Face only when you choose Download. The app checks their SHA-256 before starting them. No account is needed.
